# js-emulator

Open-source protocol emulator ASIC for the
[Jane Street protocol emulator ASIC competition](https://blog.janestreet.com/protocol-emulator-asic-competition/).

A small programmable core with an instruction set built for reading pins,
writing pins, counting cycles and precise timing, so protocols such as UART,
SPI and I2C run as firmware instead of fixed logic.

- Target: IHP 130nm CMOS5L via Tiny Tapeout, 6x4 tiles
- Submission deadline: January 18, 2027

This repository is shared with collaborators and will be public by the
submission deadline. Do not commit anything that must stay private.
